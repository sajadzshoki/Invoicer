# نسق (Invoicer)

اپلیکیشن حسابداری فارسی برای کسب‌وکارهای کوچک — راست‌به‌چپ، موبایل‌فرست، با طراحی مدرن و ممتاز.

> **وضعیت: فاز ۱ — فونداسیون اپلیکیشن و سیستم طراحی**

---

## فاز ۱ شامل چه چیزهایی است؟

- **پوستهٔ اپلیکیشن**: هدر بالایی (عنوان، بازگشت، اکشن زمینه‌ای، آواتار)، ناوبری پایین موبایل با ۵ مقصد اصلی، و سایدبار معادل در دسکتاپ/تبلت با همان معماری اطلاعات.
- **سیستم طراحی کامل و قابل‌استفادهٔ مجدد**: دکمه‌ها (اصلی/ثانویه/شبحی/مخرب/متنی/آیکونی)، ورودی‌ها (متنی، جست‌وجو، سلکت، تریگر تاریخ، مبلغ، تکست‌اریا)، چک‌باکس/رادیو/سوییچ، تب و سگمنتد کنترل، کارت، آیتم لیست، آواتار، نشان‌ها، باتم‌شیت، مودال، کشو، توست، هشدار، وضعیت خالی/خطا/بارگذاری، اسکلت و تولتیپ.
- **دو تم روشن و تاریک** با طراحی مستقل (نه معکوس‌سازی ساده) و ذخیرهٔ انتخاب کاربر.
- **صفحهٔ خانه** به‌عنوان فونداسیون بصری داشبورد: خوش‌آمدگویی، وضعیت مالی کلی، خلاصهٔ درآمد/هزینه/طلب/بدهی، اقدامات سریع، و بخش «آخرین تراکنش‌ها» با اسکلت و وضعیت خالی.
- **تجربهٔ خالی (اولین استفاده)** برای طرف حساب‌ها، فاکتورها، کالاها و تراکنش‌ها — هرکدام با آیکون، توضیح کوتاه و اکشن اصلی.
- **صفحهٔ «بیشتر»** با جای‌ناوبری برای ماژول‌های آینده: چک‌ها، هزینه‌ها و درآمدها، گزارش‌ها، تنظیمات.
- **صفحهٔ مرجع سیستم طراحی** در مسیر `/design-system` (قابل دسترس از پانوشت صفحهٔ «بیشتر») برای مرور همهٔ کامپوننت‌ها و حالت‌های تعاملی در هر دو تم.

در این فاز منطق حسابداری، اتصال به بک‌اند و هیچ قابلیت مبتنی بر هوش مصنوعی پیاده‌سازی **نشده** است؛ دکمه‌های ماژول‌های آینده با توست «به‌زودی» پاسخ می‌دهند.

## ویژگی‌های کلیدی طراحی

| موضوع | تصمیم |
| --- | --- |
| زبان و جهت | فارسی، کاملاً RTL با خواص منطقی CSS (`inline-start/end`) |
| تایپوگرافی | فونت [وزیرمتن](https://github.com/rastikerdar/vazirmatn) (نسخهٔ متغیر، سلف‌هاست) |
| اعداد | ارقام فارسی، جداکنندهٔ هزارگان «٬»، واحد تومان، قالب فشردهٔ «میلیون/میلیارد» |
| رنگ | یک رنگ برند (سبز-فیروزه‌ای عمیق)، خنثی‌های ملایم، چهار رنگ معنایی + توکن‌های مالی (درآمد، هزینه، طلب، بدهی، پرداخت‌شده، در انتظار) |
| گوشه‌ها | سیستم شعاع ۶ تا ۲۴ پیکسل + دایرهٔ کامل |
| دسترس‌پذیری | فوکوس قابل‌مشاهده، برچسب اجباری دکمه‌های آیکونی، وضعیت‌ها هیچ‌گاه فقط با رنگ منتقل نمی‌شوند، اهداف لمسی ≥ ۴۴ پیکسل |
| ریسپانسیو | ناوبری پایین در موبایل ← سایدبار در ≥۱۰۲۴ پیکسل؛ ناوبری زیر محتوا قرار نمی‌گیرد |

## معماری

```
src/
├── styles/          # ژتون‌ها (توکن‌های روشن/تاریک)، پایه، کامپوننت‌ها، پوسته
├── lib/             # ابزارهای فارسی (اعداد/مبالغ/تاریخ)، تم، ترکیب کلاس‌ها
├── components/ui/   # کتابخانهٔ کامپوننت‌های سیستم طراحی
├── app/             # پوستهٔ اپ: سایدبار، ناوبری پایین، هدر صفحه، لوگو
└── pages/           # خانه، طرف حساب‌ها، فاکتورها، کالاها، بیشتر، سیستم طراحی، ۴۰۴
```

ساختار برای افزودن ماژول‌های فازهای بعد آماده است: طرف حساب‌ها، کالاها و خدمات، فاکتورها، چک‌ها، هزینه‌ها و درآمدها، گزارش‌ها و تنظیمات — هرکدام فقط به افزودن یک صفحه و اتصال به کامپوننت‌های موجود نیاز دارند.

## اجرا

```bash
npm install
npm run dev      # سرور توسعه روی پورت ۵۱۷۳
npm run build    # بیلد تولید
npm run preview  # پیش‌نمایش بیلد تولید
```
